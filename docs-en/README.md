# SeaCode Documentation

中文: [../docs-zh/README.md](../docs-zh/README.md)

SeaCode is a local, terminal-first AI coding agent for software development work. It combines explicit model protocols, observable conversations, and progressively delivered engineering capabilities for work in a developer's own project directory.

v1 is under active development. These documents describe the confirmed product and runtime contract; the [Roadmap](./project_roadmap.md) is the source for feature availability.

| Document | Audience | Contents |
| --- | --- | --- |
| [PRD-SeaCode.md](./PRD-SeaCode.md) | Product readers, reviewers, and first-time visitors | Product position, user scenarios, capability boundaries, and acceptance criteria. |
| [Design-SeaCode.md](./Design-SeaCode.md) | Developers and architecture reviewers | Runtime model, module ownership, key flows, and failure boundaries. |
| [Manual-SeaCode.md](./Manual-SeaCode.md) | Users and maintainers | Prerequisites, YAML configuration, terminal interaction, and troubleshooting. |
| [project_roadmap.md](./project_roadmap.md) | Maintainers and reviewers | Fourteen engineering milestones, module delivery order, quality gates, and future evolution. |

## Reading Order

Read the PRD first, then the Design. Use the Manual for configuration and operation, and the Roadmap for delivery order and feature status.

## Documentation Conventions

- `docs-en/` and `docs-zh/` keep corresponding structure and product contracts.
- These documents cover public product, design, operating, and roadmap information only.
- Commands, configuration keys, and paths use code formatting; every credential in an example is a placeholder.
