# SeaCode Documentation

中文: [../docs-zh/README.md](../docs-zh/README.md)

SeaCode is a local AI coding agent runtime for software development work. It brings model connectivity, tool execution, permission control, context governance, and recoverable work state into one observable development environment.

| Document | Audience | Contents |
| --- | --- | --- |
| [PRD-SeaCode.md](./PRD-SeaCode.md) | Product readers, interviewers, and first-time visitors | Product position, user scenarios, capability boundaries, and acceptance criteria. |
| [Design-SeaCode.md](./Design-SeaCode.md) | Developers and architecture reviewers | Layering, core models, key flows, extension points, and failure boundaries. |
| [Manual-SeaCode.md](./Manual-SeaCode.md) | Users and maintainers | Installation, configuration, operation, permissions, and troubleshooting. |
| [project_roadmap.md](./project_roadmap.md) | Maintainers and reviewers | Fourteen engineering milestones, delivery order, quality gates, and evolution. |

## Reading Order

Start with the PRD, then read the Design document. Use the Manual when running the product, and the Roadmap when reviewing delivery order and engineering decisions.

## Documentation Conventions

- `docs-zh/` and `docs-en/` keep the same document structure.
- These documents record stable product, design, usage, and roadmap information.
- Commands, configuration keys, and paths use code formatting; credential examples always use placeholders.
